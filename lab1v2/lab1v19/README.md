# Лабораторна робота №1 (Варіант 2)

## Контрольні запитання та відповіді

### 1. Що таке клас та об’єкт? Яка між ними різниця?
* **Клас** — це шаблон (креслення або тип даних), який описує структуру та поведінку: які поля, властивості та методи матимуть його екземпляри.
* **Об’єкт** — це конкретний екземпляр класу, створений у пам'яті комп'ютера за цим шаблоном, що має свої реальні значення даних.
* **Різниця:** Клас існує лише у вихідному коді як опис/тип, а об'єкт виділяє реальне місце в оперативній пам'яті під час виконання програми.

---

### 2. Для чого використовуються конструктори? Чи може клас існувати без них?
* **Конструктори** використовуються для автоматичної ініціалізації початкового стану об’єкта під час його створення через оператор `new`.
* **Чи може клас існувати без них?** Так, може. Якщо розробник не описує жодного конструктора вручну, компілятор C# автоматично створює стандартний конструктор за замовчуванням (без параметрів), який заповнює поля значеннями за замовчуванням (`0`, `null`, `false`).

---

### 3. Чим відрізняється приватне поле від публічної властивості? Навіщо потрібна інкапсуляція?
* **Відмінність:** Приватне поле (`private`) доступне лише всередині самого класу і приховане від зовнішнього коду. Публічна властивість (`public property`) надає контрольований доступ до даних через блоки `get` (зчитування) та `set` (зміна).
* **Навіщо потрібна інкапсуляція:** Вона дозволяє приховати внутрішню реалізацію об'єкта і захищає дані від некоректного внесення змін ззовні (наприклад, дозволяє додати перевірку діапазону років чи значень у блоці `set`).
