### 2. Реалізував ієрархію класів

- Створив базовий клас `Vehicle` з властивістю `Speed`, конструктором та віртуальним методом `Move()`.
- Створив похідний клас `Car` з полем `NumWheels` та перевизначеним методом `Move()`.
- Створив похідний клас `Bicycle` з полем `HasGears` та перевизначеним методом `Move()`.
- Створив похідний клас `Boat` з полем `EngineType` та перевизначеним методом `Move()`.
- У кожному похідному класі налаштував конструктор із викликом `: base(speed)` для ініціалізації успадкованого поля.

```csharp
class Vehicle
{
    public double Speed { get; set; }

    public Vehicle(double speed)
    {
        Speed = speed;
    }

    public virtual void Move()
    {
        Console.WriteLine($"Транспортний засіб рухається зі швидкістю {Speed} км/год");
    }
}

class Car : Vehicle
{
    public int NumWheels { get; set; }

    public Car(double speed, int numWheels) : base(speed)
    {
        NumWheels = numWheels;
    }

    public override void Move()
    {
        Console.WriteLine($"Автомобіль їде по дорозі на {NumWheels} колесах зі швидкістю {Speed} км/год");
    }
}
```

### 3. Продемонстрував поліморфізм

У `Main` створив колекцію `List<Vehicle>`, додав до неї об'єкти `Car`, `Bicycle` та `Boat`, у циклі `foreach` викликав `Move()` для кожного елемента. Для кожного об'єкта викликалась власна реалізація методу відповідно до його фактичного типу.

```csharp
List<Vehicle> vehicles = new List<Vehicle>
{
    new Car(120, 4),
    new Bicycle(25, true),
    new Boat(40, "підвісний мотор")
};

foreach (Vehicle vehicle in vehicles)
{
    vehicle.Move();
}
```

### 4. Виконав агрегацію результатів

Обчислив середню швидкість усіх транспортних засобів у колекції за допомогою LINQ-методу `Average()` та вивів результат у консоль.

```csharp
double averageSpeed = vehicles.Average(v => v.Speed);
Console.WriteLine($"Середня швидкість: {averageSpeed:F2} км/год");
```

## Контрольні запитання

| № | Питання | Відповідь |
|---|---------|-----------|
| 1 | Що таке поліморфізм і як він реалізується в C# за допомогою `virtual` та `override`? | Поліморфізм — це здатність об'єктів різних класів по-різному реагувати на однаковий виклик методу залежно від свого фактичного типу. У C# базовий клас позначає метод як `virtual`, а похідні класи надають власну реалізацію через `override`. |
| 2 | Поясніть поняття динамічного зв'язування. Чим воно відрізняється від статичного? | При динамічному зв'язуванні (пізнє зв'язування) метод для виклику визначається під час виконання програми за фактичним типом об'єкта. При статичному зв'язуванні (раннє) метод визначається ще на етапі компіляції за типом змінної. |
| 3 | Наведіть приклад, як поліморфізм дозволяє писати більш гнучкий та розширюваний код. | Щоб додати новий транспортний засіб, наприклад `Plane`, достатньо створити похідний клас від `Vehicle` з `override Move()`. Код у `Main`, який обходить `List<Vehicle>`, змінювати не потрібно. |
| 4 | Які переваги дає використання колекцій базових типів для роботи з поліморфними об'єктами? | Єдина колекція зберігає об'єкти різних похідних типів. Один цикл обробляє їх усіх без перевірок типу через `if` чи `switch`. Агрегація (сума, середнє, максимум) виконується над спільними властивостями, а код легко розширюється. |
